# EvaGita brand kit

This package preserves the two supplied original images without regenerating or retouching the portrait.

## Files
- `portrait/evagita-portrait-original.png` — supplied portrait icon, original resolution.
- `calendar/evagita-calendar-original.png` — supplied calendar/checklist icon, original resolution.
- `app-icon-512.png` — general high-resolution app icon.
- `app-icon-192.png` — Android/PWA icon size.
- `apple-touch-icon-180.png` — Apple touch icon size.
- `favicon-32.png`, `favicon-16.png`, `favicon.ico` — browser favicon sizes.

## Important
The supplied portrait artwork has a dark background baked into the image. To avoid changing the face or accidentally damaging hair/leaf edges, this kit does not claim to include a recolored light-background portrait. A true light-theme portrait variant should be made with a reviewed foreground mask, keeping the original face pixels intact.
